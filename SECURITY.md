# Security policy

This is a private Mindclade repository. Do not file public issues for security
problems.

Report vulnerabilities, suspected credential exposure, or data-classification
violations to the security team (`@mindclade/security`) through the internal
security channel. Include the affected component, revision, and reproduction
steps.

Biological data, model artifacts, and their manifests are governed as
first-class security assets; see `BLUEPRINT.md` section 26 for classifications
and handling rules. Restricted sequences, safety corpora, and human-derived
data are never committed to Git.
